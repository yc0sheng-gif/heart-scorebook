# 拱豬計分簿

## 牌局與記分
- 固定玩家：媽媽、二姊、小青、鳳秋。
- 記分區日期時間與局數同列；日期時間字級加大 30%，局數字級加大 20%。
- 每局分數儲存時會記錄該局時間；查詢表顯示月日及時分，不顯示年份或秒數。
- 累計超過 +1000 或小於等於 -1000 時本場結束；本場累計會列在該場記錄表最後一列。
- 查詢頁提供逐局表、每場刪除及 CSV 匯出，不提供 JSON 匯出或還原。
- 正分藍色、負分紅色；筆記本記錄座位順序及下一位領牌人（即吃豬人）。

## 設定與輸入
- 字級可按類別調整；各類預設值在 65% 滑桿位置，最大可調至預設值的 130%，其他文字按比例變化。
- 可選黃綠、海洋藍、葡萄紫、夕陽陶、石板藍五種配色。
- 記分使用頁面內數字鍵盤，並限制頁面縮放以避免輸入時誤觸縮放。
- 按瀏覽器或 PWA 的返回/離開動作時，畫面先回頂端並詢問是否離開。不同瀏覽器對關閉安裝式 PWA 視窗的攔截能力不同。

## 查詢與離線
首頁點「查詢備份」，再按「查詢」顯示各場記錄。牌局資料保存在目前瀏覽器，跨裝置不會自動同步。首次在線載入後，service worker 會快取主頁和圖示，之後可離線使用。

## PWA 安裝
請將 ZIP 內容（包括 `icons` 資料夾）部署到 HTTPS 網址，例如 GitHub Pages。解壓後直接開啟 HTML（`file://`）不能安裝 PWA。Chrome/Edge 從網址列安裝圖示或瀏覽器選單安裝；iPhone/iPad 在 Safari 使用「分享」→「加入主畫面」。
