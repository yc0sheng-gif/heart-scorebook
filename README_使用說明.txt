# 拱豬／紅心大戰雙用計分簿

## 選擇記分簿
每次開啟程式先選擇：A「拱豬記分簿」或 B「紅心大戰記分簿」。畫面上方可隨時切換簿別。A 沿用既有拱豬資料；B 使用另一個獨立資料庫，包含各局記錄及筆記本，兩本不會互相混用。

## 拱豬記分簿
保留原有玩法：固定玩家、逐局記分、本場累計、筆記本、查詢 CSV、設定及配色。累計超過 +1000 或小於等於 -1000 時本場結束。

## 紅心大戰記分簿
- 標題顯示「紅心大戰記分簿」。
- 換牌方向依局數循環顯示：左方、右方、對家、不換。
- 任一玩家累計小於等於 -100 時本場結束。
- 使用獨立資料庫保存牌局和筆記本。

## PWA 安裝
將 ZIP 內檔案（包括 `icons` 資料夾）部署到 HTTPS 網址。Chrome/Edge 可從網址列安裝圖示或瀏覽器選單安裝；iPhone/iPad 使用 Safari 的「分享」→「加入主畫面」。資料保存在目前裝置的瀏覽器中，跨裝置不會自動同步。
