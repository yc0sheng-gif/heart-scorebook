# 拱豬計分簿

## 牌局記錄
- 固定玩家：媽媽、二姊、小青、鳳秋。
- 每局輸入後保存各人分數與時間；四位分數全為 0 時不允許儲存。
- 累計超過 +1000 或小於等於 -1000 時本場結束。
- 查詢備份可查看逐局表、刪除單場或匯出 CSV；已結束場次最後列顯示本場累計。
- 正分藍色、負分紅色；筆記本記錄座位與下一位領牌人（即吃豬人）。

## 設定與輸入
- 各文字類別及數字鍵盤可分別調整字級。滑桿預設在 65%，上限為該類預設字級的 210%。
- 提供八種配色：黃綠、海洋藍、葡萄紫、夕陽陶、石板藍、深海青、櫻花粉、黑曜灰。
- 輸入分數使用加寬的頁面內數字鍵盤；編輯既有局數時，儲存鍵會顯示「確定修改」。
- 已限制縮放並加入手勢攔截，降低誤觸放大的機會。

## PWA 安裝
將 ZIP 內容（包括 `icons` 資料夾）部署到 HTTPS 網址，例如 GitHub Pages。直接開啟 HTML 檔不能安裝 PWA。Chrome/Edge 從網址列安裝圖示或選單安裝；iPhone/iPad 在 Safari 選「分享」→「加入主畫面」。資料保存在各裝置自己的瀏覽器，不會自動同步。
