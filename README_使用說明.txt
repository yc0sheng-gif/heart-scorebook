# 拱豬計分簿

## 首頁與牌局
- 首頁快捷鍵以左右兩欄排列：左欄由上而下為本場累計、各局記錄、目前牌局；右欄由上而下為備份還原、設定、筆記本。
- 記分區日期時間在第一行，局數在第二行，放在同一區塊。
- 輸入分數使用頁面內精簡數字鍵盤，未輸入數值按 0 分計算，不會叫出手機系統鍵盤。
- 任一玩家累計達 +1000 或 -1000 時，本場自動結束，可開啟新場。
- 各局表為六欄：局數、四人分數、編輯筆；點筆可修改該局，列高較精簡。
- 筆記本記錄座位 1 至 4，以及下一位領牌人（即吃豬人）。

## 設定
- 「設定」中可分別調整一般文字、說明、標題、區塊標題、標籤、按鈕、輸入、玩家姓名、日期與局數、本場累計、各局紀錄、筆記本、備份頁、數字鍵盤、提示訊息與頁尾字級。
- 新安裝時每個字級滑桿預設位置約為軌道的 65%；選擇後會保存在本機。
- 可選黃綠（原色）、海洋藍、葡萄紫、夕陽陶、石板藍五種整體配色；顏色選擇會保存在本機。

## 固定玩家與計分
- 固定四位玩家：媽媽、二姊、小青、鳳秋；不提供玩家管理。
- 每局記錄四人的正負分與本場累計；正分藍色、負分紅色。

## 備份、還原與離線
沿用原版 localStorage 名稱 `heartScorebookV1` 和 JSON/CSV 匯出及 JSON 還原流程。匯入原版 JSON 時既有分數會保留並轉為固定四位玩家。新版 JSON 包含座位筆記。網站首次成功載入後，service worker 會快取主頁和 manifest，後續可離線使用。資料存在目前瀏覽器本機儲存空間，請定期匯出 JSON；不同裝置或瀏覽器不會自動同步。
