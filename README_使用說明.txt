# 拱豬計分簿

## 牌局記錄
- 固定玩家：媽媽、二姊、小青、鳳秋。
- 本場各局記錄顯示日期時間與局數；本場累計另列，達標結束後會出現在該場記錄表最後一列。
- 累計超過 +1000 或小於等於 -1000 時本場結束。
- 查詢備份可查看逐局資料、刪除單場或匯出 CSV；不提供 JSON 匯出與還原。
- 每局記錄顯示月日與時分，不含年份和秒數。

## 設定
- 各文字區域和數字鍵盤可分別調整字級。預設值在滑桿 65% 位置，最大可調至預設字級的 170%。
- 提供黃綠（原色）、海洋藍、葡萄紫、夕陽陶、石板藍、深海青、櫻花粉、黑曜灰八種配色。
- 已限制頁面縮放並加入觸控手勢攔截，降低誤觸放大的機會。

## PWA 安裝
請將 ZIP 內容（包括 `icons` 資料夾）部署到 HTTPS 網址，例如 GitHub Pages。直接開啟 HTML 檔（`file://`）不能安裝。Chrome/Edge 從網址列安裝圖示或瀏覽器選單安裝；iPhone/iPad 在 Safari 選「分享」→「加入主畫面」。資料保存在每台裝置自己的瀏覽器，不會自動同步。首次在線載入後可離線使用。
