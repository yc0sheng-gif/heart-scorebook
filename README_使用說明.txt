# 拱豬／紅心大戰雙用計分簿

## 選擇記分簿
程式啟動時選擇 A「拱豬記分簿」或 B「紅心大戰記分簿」。上方可切換簿別；兩者牌局和筆記分開保存。A 沿用原有資料庫。

## 拱豬記分簿
- 固定玩家：媽媽、二姊、小青、鳳秋。
- 新輸入局數按「儲存本局」時會檢查四人分數整組能否由合法牌面分配產生。可能發生時直接保存，不顯示複核畫面；不可能時顯示警示及可疑玩家，可返回修改或確認保存。編輯既有局數直接保存，不進入檢查。
- 因只輸入總分、不記錄各人實際取得的牌，若四人各自分數都合理但組合不成立，程式會提示無法單獨定位，請複核四人分數。
- 小滿貫時，達成者紅心計 +200，並依羊、豬、梅花10規則檢查可能分數。
- 任一累計超過 +1000 或小於等於 -1000，本場結束。

## 紅心大戰記分簿
標題顯示紅心大戰記分簿；換牌方向按左方、右方、對家、不換循環顯示；任一累計小於等於 -100，本場結束。資料庫和筆記本與拱豬分開。新局儲存時會檢查四人分數整組是否可能；可能時直接儲存，不顯示複核畫面，不可能時提示可疑玩家或要求複核整組。射月按「射月者 0 分、其他三人各 -26 分」，羊的 +10 分照常另計。編輯既有局數不複核。

## PWA 安裝
將 ZIP 內容（包括 `icons` 資料夾）部署到 HTTPS 網址。Chrome/Edge 可從網址列安裝圖示或瀏覽器選單安裝；iPhone/iPad 使用 Safari 的「分享」→「加入主畫面」。資料不會跨裝置自動同步。
