# 拱豬計分簿

## 牌局與記分
- 固定玩家：媽媽、二姊、小青、鳳秋。
- 輸入本局分數時，日期時間放第一行、局數放第二行並靠右；日期時間字級加大 30%，局數字級加大 20%。
- 每局分數儲存後會列入「查詢備份」記錄。玩家累計超過 +1000 或小於等於 -1000 時本場結束；已結束牌局的記錄表最後列會顯示本場累計。
- 查詢頁提供每場刪除及 CSV 匯出，不提供 JSON 匯出或還原。
- 本場逐局記錄可使用編輯筆修正局分；正分藍色、負分紅色。
- 筆記本記錄座位順序與下一位領牌人（即吃豬人）。

## 設定
- 字級可按類別分別調整，設定保存在本機；新安裝時滑桿預設在軌道約 65% 處。
- 可選黃綠（原色）、海洋藍、葡萄紫、夕陽陶、石板藍五款配色。
- 記分使用頁面內數字鍵盤，以縮小輸入時占用的畫面。

## 查詢與匯出
首頁點「查詢備份」，再按「查詢」顯示各場每局記錄。每場可單獨刪除，亦可匯出 CSV。牌局資料保存在目前瀏覽器的本機儲存空間。

## 離線
網站首次成功載入後，service worker 會快取主頁和 manifest，之後可離線使用。不同裝置或瀏覽器之間不會自動同步。

## PWA 安裝
- 請用 HTTPS 網址開啟（例如 GitHub Pages），或在同一台電腦的 localhost 伺服器測試；直接開啟 ZIP 裡的 HTML 檔案（`file://`）不支援安裝或 service worker 離線快取。
- Chromium/Edge：從網址列的安裝圖示，或瀏覽器選單選「安裝拱豬計分簿」。
- iPhone/iPad：Safari 開啟 HTTPS 網址，選「分享」→「加入主畫面」。
- 每台電腦的牌局資料各自存在本機瀏覽器，不會透過安裝 PWA 自動同步。此版提供 CSV 匯出供檢視，不提供資料還原。
