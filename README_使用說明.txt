# 拱豬計分簿

## 功能
- 固定四位玩家：媽媽、二姊、小青、鳳秋；不提供玩家管理。
- 每場記錄四人的每局分數與本場累計；空白分數按 0 計。
- 任一玩家累計達 +1000 或 -1000 時，本場自動結束，可開啟新場。
- 首頁有「各局紀錄」及「筆記本」快捷鍵。
- 本場累計以較大字體顯示；正分藍色、負分紅色。
- 各局紀錄以六欄表格呈現：局數、四人分數、編輯筆按鈕。編輯筆會載入該局分數供修改。
- 各局紀錄文字可選小、中、大、特大。
- 筆記本記錄座位 1 至 4，以及下一位領牌人（即吃豬人）；姓名皆由下拉選單選取。
- 匯出 Excel 可開啟的 CSV、完整 JSON 備份，並可還原 JSON。
- 保留瀏覽器本機保存及 PWA 離線快取。

## 使用
1. 部署 ZIP 內全部檔案至網站根目錄，或以支援 PWA 的伺服器開啟。
2. 點「開啟新場」，每局輸入四人得分後儲存。未填分數會按 0 分儲存。
3. 逐局紀錄按 ✏️ 可修改該局；調整文字大小選單可改變表格字級。
4. 筆記本設定座位順序和下一位領牌人，再按「儲存筆記」。
5. 任一累計達 +1000 或 -1000，本場自動結束；可開啟下一場。
6. 定期從「備份與還原」匯出 JSON。

## 備份相容性
仍使用原版 localStorage 名稱 `heartScorebookV1`，沿用 JSON/CSV 匯出與 JSON 還原流程。匯入原版 JSON 時既有分數會保留並轉為固定四人；對應依固定玩家姓名或舊備份玩家清單順序。新版 JSON 另包含座位筆記。

## 離線與資料保存
網站第一次成功載入後，service worker 會快取主頁和 manifest，後續可離線使用。資料存在目前瀏覽器本機儲存空間，清除網站資料前請先匯出 JSON。不同裝置或瀏覽器不會自動同步。
