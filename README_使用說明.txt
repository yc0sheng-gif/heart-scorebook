# 拱豬／紅心大戰雙用計分簿

## 選擇記分簿
程式啟動時選擇 A「拱豬記分簿」或 B「紅心大戰記分簿」。上方可切換簿別；兩者牌局和筆記分開保存。A 沿用原有資料庫。

## 拱豬記分簿
- 固定玩家：媽媽、二姊、小青、鳳秋。
- 新輸入局數按「儲存本局」時會依拱豬計分規則檢查四人分數是否可能，出現異常時顯示警示供確認；仍可返回修改或確認儲存。編輯既有局數直接保存，不進入複核。
- 因只輸入總分而不記錄各人取得的牌面，程式只能警示無法由規則推導的分數，無法完全核實牌面分配。
- 小滿貫時，達成者紅心計 +200，並依羊、豬、梅花10規則檢查可能分數。
- 任一累計超過 +1000 或小於等於 -1000，本場結束。

## 紅心大戰記分簿
標題顯示紅心大戰記分簿；換牌方向按左方、右方、對家、不換循環顯示；任一累計小於等於 -100，本場結束。資料庫和筆記本與拱豬分開。

## PWA 安裝
將 ZIP 內容（包括 `icons` 資料夾）部署到 HTTPS 網址。Chrome/Edge 可從網址列安裝圖示或瀏覽器選單安裝；iPhone/iPad 使用 Safari 的「分享」→「加入主畫面」。資料不會跨裝置自動同步。
