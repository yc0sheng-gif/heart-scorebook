# 拱豬計分簿

## 功能
- 固定四位玩家：媽媽、二姊、小青、鳳秋；不提供玩家管理。
- 每場記錄每局四位玩家的正負分及本場累計。
- 任一玩家累計達到 +1000 或 -1000 時，本場自動結束，可立即開啟新場。
- 筆記本記錄座位 1 至 4、下一位領牌人及吃豬者；姓名皆由下拉選單選擇。
- 正分以藍色顯示，負分以紅色顯示。
- 匯出 Excel 可開啟的 CSV，以及可完整還原的 JSON 備份。
- 保留瀏覽器本機保存及 PWA 離線快取。

## 使用
1. 解壓縮後將全部檔案部署到網站根目錄，或用支援 PWA 的本機/網站伺服器開啟。
2. 點「開啟新場」，每局輸入四人的實際得分後儲存。
3. 筆記本填寫座位順序、下一位領牌人和吃豬者，再按「儲存筆記」。
4. 任一累計達到 +1000 或 -1000，本場會自動結束；按「開啟新場」開始下一場。
5. 定期從「備份與還原」匯出 JSON；CSV 適合用 Excel 檢視。

## 備份相容性
仍使用原版 localStorage 名稱 `heartScorebookV1`，並沿用 JSON/CSV 匯出與 JSON 還原流程。匯入原版 JSON 時，既有每局分數會保留並轉為固定四位玩家。對應依玩家姓名（姓名符合固定名單時）或舊備份玩家清單順序；匯入後播放器名固定為本版四人。新版完整 JSON 另包含座位筆記。

## 離線與資料保存
網站第一次成功載入後，service worker 會快取主頁和 manifest，後續可離線使用。牌局資料存在目前瀏覽器的本機儲存空間，清除網站資料前請先匯出 JSON。不同裝置或瀏覽器之間不會自動同步。
