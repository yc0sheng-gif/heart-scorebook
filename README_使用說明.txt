# 拱豬計分簿

## 記分畫面
- 點選任一分數欄會開啟數字鍵盤並將記分卡捲至頂端；手機窄螢幕版縮緊玩家卡片，四位玩家姓名、完整鍵盤與「儲存本局」按鍵可同時顯示。
- 數字鍵盤採四欄排列，較容易點選。
- 逐局列表最上方顯示累計，最新局排在最上；累計列有橙色粗底線。
- 四位分數全為 0 時不允許儲存。

## 設定及牌局
- 四位固定玩家：媽媽、二姊、小青、鳳秋。
- 字級可逐類調整，滑桿預設約 65%，最高為預設字級的 210%。提供八組配色。
- 編輯已記錄局數時，儲存按鍵會顯示「確定修改」。
- 累計超過 +1000 或小於等於 -1000 時本場結束。

## 查詢備份
查詢頁顯示每場逐局表和結束場次累計，可刪除單場或匯出 CSV；不提供 JSON 匯出與還原。牌局資料保存在目前裝置的瀏覽器中。

## PWA 安裝
將 ZIP 內容（包括 `icons` 資料夾）部署到 HTTPS 網址，例如 GitHub Pages。Chrome/Edge 可從網址列安裝圖示或瀏覽器選單安裝；iPhone/iPad 使用 Safari 的「分享」→「加入主畫面」。資料不會自動跨裝置同步。
