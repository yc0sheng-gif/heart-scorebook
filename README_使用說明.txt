# 拱豬計分簿

## 功能
- 固定四位玩家：媽媽、二姊、小青、鳳秋；不提供玩家管理。
- 首頁快捷鍵：本場累計、各局紀錄、筆記本、設定。
- 每局輸入四人分數；未輸入數值會以 0 分儲存，開始輸入時游標在第一位玩家。
- 分數輸入使用頁面內精簡數字鍵盤，避免叫出占用較大畫面的手機系統鍵盤。
- 設定頁提供各文字類別的獨立字級滑桿，包含標題、說明、按鈕、姓名、累計、逐局表、筆記本、備份頁與鍵盤；設定保存在本機。
- 任一玩家累計達 +1000 或 -1000 時，本場自動結束，可開啟新場。
- 各局表為六欄：局數、四人分數、編輯筆。點筆可修改該局。
- 筆記本記錄座位 1 至 4，以及下一位領牌人（即吃豬人）。
- 正分藍色、負分紅色；維持 CSV/JSON 備份、JSON 還原和 PWA 離線功能。

## 使用
1. 部署 ZIP 內全部檔案至網站根目錄，或以支援 PWA 的伺服器開啟。
2. 點「開啟新場」，輸入每局四人的得分；空白會以 0 分計算。
3. 點「設定」調整不同文字類別的大小；點逐局紀錄中的 ✏️ 修改該局。
4. 筆記本設定座位順序及下一位領牌人，再按「儲存筆記」。
5. 任一累計達 +1000 或 -1000，本場自動結束；可開啟下一場。
6. 定期從「備份與還原」匯出 JSON。

## 備份相容性
沿用原版 localStorage 名稱 `heartScorebookV1` 和 JSON/CSV 匯出及 JSON 還原流程。匯入原版 JSON 時既有分數會保留並轉為固定四位玩家。新版完整 JSON 包含座位筆記。

## 離線與資料保存
網站首次成功載入後，service worker 會快取主頁和 manifest，後續可離線使用。資料存在目前瀏覽器本機儲存空間，清除網站資料前請先匯出 JSON。不同裝置或瀏覽器不會自動同步。
