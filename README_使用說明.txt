# 紅心大戰手機電子計分簿 V1

## 功能
- 玩家名單與四人座位選擇
- 每局換牌提醒：左、右、對面、不換，四局循環
- 每局登錄四人紅心分數、♦J、♠Q、射月
- 本場累計、結束結算、歷史牌局與排行榜
- 匯出 Excel 可開啟的 CSV，以及完整 JSON 備份
- 手機 PWA，可加入主畫面

## 計分方式
每位玩家每局：
- 紅心牌：輸入該玩家本局紅心牌分數合計（負數）
- ♦J：勾選加 10
- ♠Q：勾選扣 13
- 射月：勾選後，紅心及♠Q合計改為 +26；♦J仍獨立計算 +10

例如：紅心分數 -8、拿到♦J、沒有♠Q，該局為 +2。
如射月且拿到♦J，該局為 +36。

## 重要資料保存說明
V1 使用瀏覽器 localStorage，資料只存在目前這支手機、目前瀏覽器的網站資料中。
- 不要清除瀏覽器網站資料或重設手機前未備份。
- 每月匯出 CSV 和 JSON，並將 JSON 備份放到另一個安全位置。
- CSV 可用 Excel 開啟；JSON 用於完整還原。
- 此版本尚未提供跨手機雲端同步。

## GitHub Pages 部署
1. 在 GitHub 建立一個新的 Public repository，例如 `heart-scorebook`。
2. 解壓縮 ZIP。
3. 將 `index.html`、`manifest.webmanifest`、`sw.js` 三個檔案上傳到 repository 根目錄。
4. Repository → Settings → Pages。
5. Source 選 `Deploy from a branch`；Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
6. 等待部署完成，開啟 GitHub Pages 顯示的網址。
7. 手機用 Chrome 開啟網址 → 右上角選單 →「新增至主畫面」或「安裝應用程式」。

## 第一次使用
1. 打開「玩家管理」，新增四位玩家姓名。
2. 回「目前牌局」，依東、南、西、北選擇四人。
3. 開始牌局。每局結束輸入四人分數並儲存。
4. 本場結束按「結束本場並結算」。
5. 到「歷史紀錄」查看各場；「排行榜」查看累積成績。
6. 每月匯出 CSV 與 JSON 備份。

## 注意
- 請先用測試資料試玩數局，確認射月規則符合你們實際採用的算法，再輸入正式成績。
- 若修改了已記錄的局數，請確認修改後的數字；V1 的修改功能以總分重新填入紅心欄位，適合直接修正總分，但不會保留原本各種牌型的明細。
